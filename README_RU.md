# PC Workshop 3D — Android prototype

Отдельный проект на Godot 4.4.1. Целевая платформа — Android, альбомная ориентация, Compatibility renderer.

## Сборка APK через GitHub Actions

1. Создай пустой GitHub-репозиторий.
2. Распакуй ZIP так, чтобы `project.godot`, `main.gd`, `main.tscn`, `export_presets.cfg` и папка `.github` находились **в корне репозитория**. Не загружай лишнюю внешнюю папку `PCWorkshop3D`.
3. Загрузи файлы в ветку `main`.
4. Открой вкладку **Actions** и выбери **Build PC Workshop 3D APK**.
5. Нажми **Run workflow** (или дождись автоматического запуска после push).
6. После успешного выполнения скачай `PCWorkshop3D-Android-APK` в разделе Artifacts.

Workflow скачивает официальные Godot 4.4.1 Android export templates при каждом запуске и использует Android SDK, Android SDK 34, build-tools 34.0.0, command-line tools, NDK 23.2.8568313 и CMake 3.10.2.4988404 и временный debug keystore. Секреты GitHub для debug-сборки не требуются.

## Что находится в прототипе

- 3D-мастерская и рабочий стол с открытым корпусом.
- Перемещение стрелками на экране или WASD на ПК; осмотр свайпом по правой части экрана.
- Выбор комплектующих, отображение выбранной детали в руках.
- Прицеливание на слоты, подсветка подходящего/неподходящего слота, поворот детали и установка.
- Магазин, баланс, заказ и проверка собранного ПК.

## Важно

Архив содержит исходный проект и workflow сборки. В workflow добавлен отдельный шаг загрузки официального архива export templates Godot 4.4.1, поскольку в используемом CI-контейнере шаблоны отсутствовали. Успешная загрузка APK подтверждает экспорт, но запуск и управление на реальном Android-устройстве нужно проверить отдельно.


### Подпись APK в GitHub Actions

Для CI используется `--export-debug`: Godot подписывает отладочный APK debug-keystore из настроек EditorSettings. Параметр `package/signed` выключен, чтобы экспортный профиль не требовал release-keystore, которого нет в репозитории. Не загружайте приватный release-keystore в GitHub вместе с исходниками.
